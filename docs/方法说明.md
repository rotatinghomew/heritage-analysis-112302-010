# 共现诊断与补扫规划方法说明

配套代码：`reading_diagnosis/` 与根目录 `analyze.py`。所有输入均为合成样例，
本文件说明从原始阅览链到三分类、样本外检验、补扫台账的判定口径。

## 1. 实体与字段口径

| 概念 | 字段/载体 | 口径 |
|---|---|---|
| 研究任务 | `session`（代理） | 数据没有独立研究任务字段，以会话作为最小任务单元；接入真实数据时应替换为任务号 |
| 作品（拓片） | `work` | 比较与闸门的对象；同一件作品的多次拍摄不重复加权 |
| 拍摄件 | `scan`（support-1） | 质量须为 `comparable` 且授权区间覆盖评估时点才具对照资格 |
| 装订册 | `edition` | 补扫调度单元；一册可含多件作品，开合按册内作品逐项计 |
| 馆点/时间片/可见集合 | `venue` / `occurred` 月份 / `visible` | 诊断结果保留这四维差异，不用全局共现抹平 |
| 治理状态 | support-2 | `scope=reviewed` 且 `version=active` 才为受控；缺报时结论降级 |

空值一律解析为 `None`（未知）。文件缺失是**缺报**，与数值零分开；规划器在约束
缺报时返回 `indeterminate`，不会把缺报当成额度为 0 来排期。

## 2. 事件级有效性（protocol.py）

1. `search`：只产生曝光证据。闭馆时段内的搜索曝光按协议不计“可见未点击”，
   其 `visible` 不进入假关联证据。
2. `compare`：授权为 `valid` **且**可见集合内每件作品通过对照资格闸门
   （存在区间覆盖的 `comparable` 拍摄件）才构成有效观察。
   - 常设许可为 `restricted/onsite` 但事件授权 `valid`：标记 `temporary_grant`，
     表明观察靠临时阅览授权成立，常设可见性并不支持；
   - 闸门失败（如只有 `low_quality` 拍摄件）：可见但不可比，不构成观察。
3. `request` + `restricted`：受限/未兑现请求，记为受阻需求，永不计为观察；
   预约席占满导致的放弃在数据中以这类未兑现请求体现。
4. `open`：继续阅读同一材料，单作品访问不产生组合；同会话重复打开在聚合层折叠。
5. 闭馆（可选 `closures.csv`）命中的事件标 `blocked`，不能当作负样本。

## 3. 组合构建、去重与三分类（pairs.py）

候选组合来自事件可见集合内的两两配对，按 `(会话, 组合)` 去重：
同一会话对同一组合的多次 compare/open 只保留一条观察，多次拍摄不增加权重；
同一装订册承载只打 `same_edition_bundle` 风险标记，不自动加权。

| 分类 | 判定条件 | 业务含义 |
|---|---|---|
| `supported` | 至少一个会话存在有效 compare 观察 | 真正有材料与授权支持的比较需求 |
| `spurious` | 无有效观察，仅有搜索共曝光，或可见但闸门失败 | 目录推荐即可制造的关联，下载共现会持续偏向这类“本来最容易拿到”的材料 |
| `inconclusive` | 存在受阻/未兑现请求，但从未获得观察机会 | 无证据判真伪，不能按假关联删除，也不能按真需求补扫 |

**独立业务解释**：低频（≤2 次）未满足请求且题录中没有达到 `comparable` 的
替代件时，`inconclusive` 组合会带 `requires_business_justification`，要求馆员
登记具体研究任务与不可替代原因后才能进入补扫决策。纯曝光的 spurious 组合没有
请求行为，不触发该规则。

**替代件边界**：只有 `substitutes.csv` 明确登记替代对象且质量为 `comparable`
时，替代件才承担对照。低质量替代不消除解释义务；不同研究组共用一本替代合集，
不等于各自具备原件比较条件。

## 4. 样本外检验（留一会话）

对每个会话做留一折：用其余会话中选出的 supported 组合，检查保留会话是否复现
有效观察。单一会话支撑的组合必然得到 `in_sample_only_fails_holdout`，只能算
样本内线索；在未参与选组合的记录中复现才可升级为
`confirmed_out_of_sample`。非 supported 组合标记 `not_tested`。

## 5. 补扫规划（planner.py）

1. 以 `edition` 为候选单元，逐作品核查质量缺口与授权区间；没有扫描质量缺口的
   装订册不进补扫清单（纯授权问题走授权/政策路径，补扫解决不了）。
2. 对每个候选测算：
   - `newly_realizable`：补扫合格 + 区间续期后能新增的可比较机会及交付方式；
   - `remains_blocked`：另一涉及作品常设受限，本册补扫后仍无法兑现完整组合；
   - `realizable_delta / blocked_count`：机会增量与残留风险。
3. 排期约束来自可选 `constraints.csv`（开合承受次数、馆点工时、锁定借阅、
   许可区域）。缺报时输出 `indeterminate` 与所需字段，禁止跨许可区域转交，
   锁定借阅期内不得排期，开合按册内作品逐项累计。
4. 时间窗风险：授权剩余 ≤60 天的拍摄件、待解释的低频请求全部显式列出。

## 6. 影响台账（许可收紧 / 质量不达标）

逐（场景 × 组合 × 研究组）给三态处置：

- `usable_as_agreed`：该组此前已有有效交付，按协议原授权留痕，收紧不追溯；
- `alternative_delivery`：无交付留痕但存在馆内监督阅览等替代路径；
- `postponed`：无留痕、无替代（或新扫件质量不达标），停止后续配送并推迟。

## 7. 已知局限（由合成数据决定）

- 无研究任务字段，以会话代理任务；无显式预约席容量字段，放弃行为通过未兑现请求体现；
- 无闭馆、替代题录、约束表输入，相关结论以缺报声明降级，而非假设默认值；
- 单一会话样本使留一检验无法确认任何组合——这是数据量的真实结论，不是方法失败。
